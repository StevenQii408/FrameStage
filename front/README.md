# FrameForge · AI 分镜工作台

2026-11-11 媒体预览：输入节点原片播放器使用按需加载的 `CanvasVideoPlayer`，提供更大画面、自定义播放条及真实 PySceneDetect 切点圆点（读取 RawShot，使用原片时间，不读取生成阶段）。图片／视频资产双击在原节点放大，同一时刻一个；关闭恢复视口、原位置和生成参数。视频截帧菜单支持首帧／当前帧／尾帧，真实解码像素保存为新的只读图片参考节点，Blob 存 IndexedDB，单步撤回，刷新恢复；截取后恢复原播放位置与状态。无新增大型依赖，播放器仅打开时加载。

节点拓扑式 Vue 3 前端工作台：项目 → 独立画布 → 输入任务 → 分镜 → 画面/视频 Prompt。启动进入项目首页，支持创建、搜索、分页加载、重命名、删除和恢复；同一画布支持多个分析与生成任务。旧画布和 `job_ids` 链接一次性迁入“旧工作台”，原数据与本地图片保留。

有完整派生数据时，输入任务直接分叉连接各“生成片段”，不再用场次面板包住片段。多来源片段收拢为无边框 3D 叠图，单来源只显示一个封面；原片时长和建议生成时长分别展示。展开的是已保存的来源证据，不是重新拆出的生成镜头；原始切点继续在来源详情的“证据与来源”页追溯。

每个片段（包括单来源片段）均在分支末尾常驻青绿色“完整事件 Prompt”节点。它复用后端该片段的 canonical Seedance 内容和原 Prompt ID，包含主体、规格、动作阶段、摄影、画风与收束；支持复制、统一详情 Host 阅读和接入视频生成草稿。不会拼接单镜 Prompt，不重新调用模型，不伪造结果。选中片段时仅额外展示首帧卡，不重复创建第二份视频卡。

各片段可以独立展开与收拢，来源按时间顺序每行最多四张，全部展示，不分页；总 Prompt 跟随分支末尾。普通单击只选中，叠卡封面保留原有展开／收拢；点击“查看详情”或按 `I` 才查看细节。展开、拖拽和尺寸变化只重排当前任务，保留根节点、手动位置及其他任务位置。状态按片段 ID 保存，兼容迁移旧场次展开记录；删除与撤回同时处理片段、来源及相关引用。来源卡可展示精确匹配的已保存动作证据帧，但不会改动首帧输出端口、帧时间顺序或首帧 Prompt。

常驻右侧栏及其恢复按钮已移除。画布、镜头列表和时间轴共用单例 `NodeDetailsHost`：可拖动、非模态，不挤压画布，也不改变视口。概览、证据与来源、检查与记录按需显示，复核记录／轮询只在检查页读取；输入任务的“任务报告”与“复核与实验”页承载任务级报告和事件分镜实验。来源跳转携带项目／任务／镜头身份，可返回原生成片段，避免跟随当前选中任务误跳。详情 Host 与生成节点下方 composer 互斥，关闭详情不取消后台任务。

“全局画风”面板最多展示三个经证据核验的配方，展开可看后端库内完整 Prompt。点击仅填入草稿；保存／应用是明确的创作选择，记录版本与库来源，不修改原片观察。手工修改草稿则按手动编辑保存。

打开 **http://127.0.0.1:5174/**。Vite 使用固定端口与 `strictPort`，避免和其他本机项目共用 5173 后自动漂移；后端已放行 5174，保留旧 5173 兼容。

进入新项目时画板为空且只使用暗色主题，双击空白处可创建视频输入、剧本输入、图片生成或视频生成节点。有派生结果时使用上述片段分支；没有派生结果的旧任务继续使用场次展示兼容路径。全部分镜不会因缩放而从逻辑画布和小地图消失。删除输入根节点会关闭对应 SSE、对运行中的分析发出取消请求，并级联移除该任务的分析节点；手动创建的生成节点保留为孤立节点，只断开来自已删除任务的线。Delete / Backspace 和 ⌘Z / Ctrl+Z 支持删除与撤回；已经发出的云端请求可能产生费用，撤回不会自动重新提交被取消任务。历史任务的通用图片/Kling 数据仍可读取和导出。视频根节点保留蓝紫极光，剧本根节点使用蓝橙双层光晕。原比例四帧灯箱、证据／切点／合同详情、多任务 SSE、刷新恢复、列表、时间轴、JSON 导出和减少动画模式继续可用。

图片／视频生成草稿支持参数编辑及后端任务：一个左侧端口接收类型匹配的 Prompt 和图片，右侧为输出端口。空图片节点手工上传后成为只读参考资产，固定原图比例、仅有右侧输出，不再接收生成输入或打开 composer；需要生成时连接到新的生成节点。视频节点上传图片仍作为首帧参考，不是视频产物，本轮仍不支持视频文件导入。已有生成尝试／成功版本的节点添加图片仅作为参考输入，保留产物与历史。连线不会把参考图传播成所有节点的生成结果；生成连线可单击选中并用 Delete／退格键断开，⌘Z 可撤回，端口具备扩大的磁吸命中范围。

选中可生成节点时，在节点下方显示一张浮动参数面板，参考图缩略图位于 Prompt 上方，支持多图选择和首帧指定；此时关闭其他节点的详情 Host。输入 `@` 可用缩略候选及方向键、Enter、Esc 选择参考图，插入后显示带1:1缩略图的行内标签，悬停可完整预览原图。编辑器保存纯文本 `@图片N`，支持中文输入、纯文本粘贴及独立的文字撤回；编号跨刷新及断线保留，缺失引用会阻止提交，不能把原 `@图片1` 自动重指向其他图。展开图标打开相同的完整 Prompt 编辑框，与下方文本同步；连接 Prompt 的编辑保存在本节点，不修改上游。

空生成草稿的占位框随所选画幅调整；上传参考资产始终保持原图比例，已有生成产物则按置顶版本的真实比例显示，修改草稿规格不会撑变旧画面。图片完整显示而不裁剪，切换历史同步端口和小地图。拖拽只移动节点，可生成节点单击才打开下方参数卡。视频时长和规格读取后端模型能力，当前 Wan 3.0 支持2–30秒整数；历史参数保留读取，不符合当前范围时提示修改后提交。

同一生成节点可以保存多个真实成功版本，最新交付默认置顶，历史列表支持预览、原始 Prompt 与手动置顶。切版只改变封面和下游输出，不重写当前草稿或历史 Prompt；下游的 `@图片N` 编号保持稳定，但版本变化会使旧任务按输入变化标记过期。失败、取消或新尝试处理中保留旧产物；重复 SSE／REST 不重复记版或抢回用户选择。版本与置顶随画布恢复，后端校验其项目、节点及实际交付来源。

双指滚动平移、捏合缩放；V 完整包含框选、H 抓手，空格或中键临时平移。选中外框保留约 12px 的屏幕内边距。支持修饰键增减选择、⌘/Ctrl+A 全选、整组移动／删除和一次撤回。分析子节点只移出画布，后端结果仍可读取；三指框选依赖 macOS 已启用系统“三指拖移”。项目导航与保存状态移至右上操作组，抓手／缩放工具位于画布底部，操作引导已移除。

⌘/Ctrl+Z 在 window／document 捕获阶段处理 `keydown`，以可取消的 `beforeinput historyUndo` 去重兜底。真实文本编辑保留原生文字撤回；只读 Prompt 和非模态详情走画布撤回，空历史也消费事件。真正模态中的非编辑区域会消费事件但不撤回底层画布，避免 Safari 误执行“撤销关闭标签页”。点击非控件画布会回焦，正文选中、滚动和控件不抢焦。历史仅保存在当前会话，刷新／切换项目不恢复；撤回不自动重发模型或生成请求。

后端支持可配置的千问图片与 Wan 视频生成服务。未启用时，下方编辑卡的“校验并保存任务”仅保存不可变输入快照，显示“等待接入生成 API”，不发起外部请求。启用后，每项目共用一条 SSE，支持持久游标、去重、刷新恢复和页面隐藏停流。节点生成中使用轻量 Canvas 星海潮汐及数字进度：双层波面与明亮星云随进度自底向上涨，上方保留稀疏暗星；真实 Provider 百分比优先，仅返回阶段时明确标注“预计”，估算不写入任务、SSE 或历史，也不代表完成时间，实际成功后才显示100%。星空共用一条帧调度，无新增图形依赖，隐藏、屏外及减少动画模式停止粒子动画。

生成失败立即停止潮汐，卡片显示具体中文原因与下一步提示，区分上游算力不足、限流、余额／额度、鉴权、内容审核、网络和超时等情况。仅按后端公开错误码分类，不把未知原因猜成算力不足。失败保留置顶产物和历史，取消／中断单独展示；编辑新输入后不会沿用旧失败状态。云端原始消息不进入卡片，不自动重新提交付费生成请求。

本机图片继续保存在 IndexedDB，节点、接线、草稿、成功版本及置顶引用保存在画布状态；已提交任务与资产另存后端。替换参考图不物理删除旧 Blob，撤回可恢复；生成历史可刷新恢复，画布 Undo 历史仅限会话。修改输入会标记旧任务过期，不覆盖原快照；显式重试创建独立尝试。未确认提交的幂等标识在请求前保存，响应丢失或刷新后重用；恢复和撤回不会自动发起生成。删除进行中的生成节点会取消对应任务并关闭 SSE，撤回后重新读取该任务状态。任务 JSON 导出仍不代表包含画布／本机图片的完整项目备份。

代码职责：`useGeneratorEdits` 管理本机编辑，`useGeneratorAssets` 管理参考图生命周期，`useGeneratorTasks` 管理后端任务与 SSE，`generatorVersions` 管理不可变产物历史和置顶；`useNodeDetails` 管理详情作用域，`NodeDetailsHost` 按需展示，`useCanvasUndo` 管理全局撤回事件；`App.vue` 负责画布协调。参数与服务商能力由后端再次验证，只有成功返回、类型匹配的本节点产物才可作为生成输出。

开发环境使用 Node.js 22。`typecheck` 独立检查 Vue／TypeScript 类型，不能以 Vite 构建替代。网页对写入请求自动向后端 bootstrap 本机会话，只在内存保留令牌；后端重启导致明确的令牌拒绝时最多刷新并重试一次，网络失败不自动重提生成。认证与非默认端口配置见根目录 `SECURITY.md`。

服务端保存和本机缓存均失败时，可从项目名旁下载当前窗口的草稿。分析任务结束后会自动读取最终结果，连续读取失败时，输入节点提供“重新读取结果”按钮。

撤回只恢复本地编辑状态，保留其他节点最新的远程任务身份和已交付版本；撤回已提交输入节点与正常删除共用隐藏／取消规则，避免刷新复活。图片保存以 IndexedDB 事务完成为准，提交失败不会报告保存成功。
