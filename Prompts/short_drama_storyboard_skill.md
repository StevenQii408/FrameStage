# AI 短剧剧情与分镜 Skill

将故事写成可生成、可剪辑的镜头计划，而不是文学梗概。默认用中文输出；未指定画幅时，默认以 9:16 竖屏短剧处理。所有下游提示词默认**无台词、无人物说话、无任何可读文字**，以动作、表情和环境声叙事。

## 先收集最少信息

若用户未提供下列关键信息，只追问 2-3 项，优先级从高到低：

1. 画幅与成片时长：`9:16` / `16:9`，单集或总时长。
2. 核心冲突和结尾意图：想让观众在结尾知道什么、误会什么或等待什么。
3. 主角、关系、地点和题材气质。

信息仍不全时，明确采用的默认值：现代现实题材、两位主要角色、一个可控场景、3-6 镜、无 IP、每镜 **4-5 秒**。用户指定时长时，严格服从用户要求。不要因小信息缺失停止创作。

## 全局提示词硬约束

每条将交给图生视频的镜头提示词都按下列顺序开始，不能先写空泛的“电影感”：

```text
主体：{人物/动物/物件、外形、服装、姿态、固定道具}。
场景：{地点、时间、空间关系、可见光源、环境状态}。
```

紧接着再写动作、镜头、整体画面风格和声音。每镜都必须附带以下约束：

```text
无台词，无人物说话，无旁白；不生成任何文字、字幕、招牌文字、logo、水印或可读符号。
```

在项目锁定表后追加“整体画面风格块”，全片逐字复用：

```text
整体画面风格：{动画/写实/定格等媒介}，{角色与表情要求}，{光影、材质、色彩}，{电影级动画/摄影品质}。
```

用户明确指定时可以写：`采用 Disney《魔法满屋》风格，高品质 3D 角色，超丰富面部表情，电影级动画品质。` 若目标平台拦截 IP，再改成：`明亮拉美魔幻家庭动画美学，高品质 3D 角色，超丰富面部表情，饱和暖色、繁茂植被与电影级动画品质。`

## 工作流

### 1. 建立故事引擎

先写出以下五项，再写镜头：

| 项目 | 要求 |
|---|---|
| 一句话故事 | `谁`为了`什么`，在`什么阻碍`下，必须做出`什么选择`。 |
| 角色目标 | 每名主要角色都要有当下可见的目标，不只写性格标签。 |
| 冲突 | 指定外在阻碍与情感/信息冲突各一个。 |
| 转折 | 用一个可被看见或听见的动作、物件、信息改变局面。 |
| 结尾钩子 | 留下未解问题或迫近代价；不要用“未完待续”字卡代替钩子。 |

按成片类型选择节奏：

- **9:16 短剧**：前 0-2 秒直接给冲突/异常结果；中段用动作、表情和物件反应升级；结尾停在未解答的反转或反应。
- **16:9 短片**：先用建立镜头交代空间关系，再进入人物目标与冲突；结尾可以是开放式余味，也可以是完整选择的后果。
- **单场戏**：围绕一次信息揭示或一次选择，不要塞进“相遇、误会、追逐、和解、反转”五件大事。

### 2. 先锁一致性，再拆镜

只要有 3 镜以上或角色跨镜出现，先输出“项目锁定表”。后续每镜必须复用同一措辞，不得在中途重新概括人物外貌。

| 编号 | 角色/场景 | 可识别特征与服装材质 | 固定道具 | 两个瑕疵或状态锚点 |
|---|---|---|---|---|
| P1 | | | | |
| P2 | | | | |
| S1 | | | | |

再输出“氛围锁定块”：画幅、色调、时间、主要光源、摄影风格、整体画面风格、环境声音。每镜复制这一块的关键措辞，防止人物、光线、服装和调色漂移。

### 3. 选择镜头语法

镜头服务信息和情绪，不为炫技。每镜最多一个主要镜头运动；不要同时要求“固定机位、环绕、快速摇镜和慢推”。

**景别不等于焦段。** 景别说明画面取景范围（特写、中景、全景）；`35mm`、`50mm`、`85mm` 是镜头焦段。每镜同时给出两者，并写入下游提示词：

| 焦段 | 适用画面 | 使用提醒 |
|---|---|---|
| 24-28mm | 建立镜头、狭窄空间、强透视运动 | 人脸靠近边缘会变形。 |
| 35mm | 双人中景、走位、带环境的叙事 | 作为短剧默认焦段，兼顾人物和空间。 |
| 50mm | 自然视角的中近景、单人反应 | 适合表情和手部动作。 |
| 85mm | 近景/特写、隔着空间观察人物 | 背景压缩明显，避免用于狭窄双人全景。 |

| 剧情目的 | 优先镜头 | 说明 |
|---|---|---|
| 建立地点、距离、危险 | 大全景/建立镜头，缓慢横移或静守 | 让观众先读懂空间。 |
| 无台词对峙 | 单人中近景正反打、过肩镜头 | 用眼神、手势和物件反应升级；保持 180 度轴线。 |
| 秘密或线索 | 手部/物件特写、焦点转换 | 先让观众看见，再让角色反应。 |
| 亲密或遗憾 | 双人近景、缓慢推近/后拉 | 用手势、停顿和距离承载情绪。 |
| 追逐或动作 | 全景起势、侧向跟拍或低机位跟拍 | 连续镜头的运动方向一致。 |
| 悬疑 | 画框构图、局部遮挡、缓慢推近 | 留信息，不要用快速乱切代替紧张。 |

画幅规则：

- **9:16**：对话以脸部和手部为主要信息；脸放在画面上中部，眼神方向留有空间；避免横向黑边和远得看不清的双人全景。
- **16:9**：用前、中、后景建立人物关系和环境尺度；建立镜头、双人调度和横向运动更有价值。

### 4. 把剧情拆成可生成的镜头

每镜只包含一个主要动作和一个情绪/信息变化。动作必须能在该镜时长内完成；复杂行为拆为起身、走近、递出、接住、反应等独立镜头。

每一镜都按下表输出：

| 字段 | 写法 |
|---|---|
| 镜号与时长 | 默认 `镜 03，4-5 秒`；用户指定时长时按要求。 |
| 主体与场景 | 必须排在该镜提示词最前：`主体：... 场景：...`。 |
| 戏剧功能 | 钩子、交代目标、升级、揭示、反应、悬念。 |
| 起始状态 | 0 秒时每个人在哪、朝哪、手里有什么、情绪如何。 |
| 主要动作 | 一个清晰动词链，不超过一件关键行为。 |
| 结束状态 | 该镜结束时留下的姿势、物件和情绪。 |
| 景别/焦段/构图 | 景别 + 焦段（如 `35mm` / `50mm`）+ 人物位置、前中后景或留白。 |
| 运镜 | 一项明确运动或静止规则。 |
| 整体画面风格 | 从氛围锁定块逐字复用。 |
| 声音 | 仅环境声/拟音/配乐；无台词、无旁白、无人物说话。 |
| 出场与承接 | 出画方向/状态，以及下一镜从什么方向或什么状态接入。 |
| 图生视频备注 | 告知下游 Skill 首帧要冻结的动作起点。 |

### 5. 处理剪辑连续性

提交前逐项检查：

- 相邻镜头中人物的左右位置、视线、行走方向和手持物是否接得上。
- 角色的服装、道具、伤痕、天气、时间和色调是否与锁定表一致。
- 对话是否遵守 180 度轴线；如需越轴，先用中性双人镜或可见的移动镜头重建空间。
- 动作是否有起始、过程、结果；不要从“手空着”跳到“物品已经递出”。
- 每镜是否都能单独生成；无法一句话描述的镜头必须拆开。

## 固定交付格式

按以下顺序交付，除非用户只要求其中一项：

1. `创作假设`：仅列未由用户提供、但已采用的关键默认值。
2. `故事引擎`：一句话故事、角色目标、冲突、转折、结尾钩子。
3. `项目锁定表`：3 镜以上必给。
4. `节拍表`：用时间或镜号说明钩子、升级、转折、悬念/收束。
5. `风格决策`：说明主风格、辅风格、为何适合本片，以及全片复用的风格块。
6. `逐镜分镜表`：使用“镜头字段”中的全部项目；每镜先写 `主体`、再写 `场景`。
7. `连续性与生成检查`：列出已验证的承接点和风险镜头。
8. `交接给视频提示词 Skill`：逐镜列出首帧应冻结的起始动作。

## 动画与特效风格选择器

先按故事内容选择**一个主风格**，最多添加一个辅风格。主风格定义角色、场景、色彩和材质；辅风格只能定义特效、转场或动作残影。不要在一条 4-5 秒镜头中混用三种以上美术体系。

### 选择流程

1. 判断叙事目标：青春治愈、喜剧反击、恐怖不安、史诗登场、东方奇幻、强动作或产品视觉化。
2. 判断主体与动作：人物表情优先用柔光/绘本类；冲击动作优先用漫画爆破/水墨动作；空间不安优先用剪纸几何类。
3. 判断生成难度：4-5 秒内只保留一个“特效阶段”，如“火星聚拢”或“墨迹挥出”，不要写聚拢、爆炸、变形、穿越、消散五连段。
4. 输出一段 `整体画面风格`，并把同一段逐字复制到每镜；每镜再单独补充一个可见特效动作。

### 风格匹配表

| 内容/情绪 | 主风格 | 可选辅风格 | 选择理由 |
|---|---|---|---|
| 青春、重逢、雨后治愈、城市奇遇 | 天气光影日系动画 | 手绘物理光效 | 人物表情与天空/反射光共同叙事。 |
| 喜剧反击、强钩子、夸张转折 | 极简波普爆破动画 | 手绘速度线 | 低成本也能读出冲击和节拍。 |
| 奇迹、疗愈、物件被唤醒 | 手绘物理光效 | 古朴魔法 | 特效可被清楚拆成线条、火星、烟雾或水流。 |
| 秘密、童话惊悚、空间错位 | 剪纸贴图与诡异几何 | 古朴魔法 | 轮廓、阴影与几何裂缝比复杂怪物稳定。 |
| 召唤、王座、世界观揭示 | 神性大魔导 | 新国潮东方奇幻 | 用规模、层级和光束呈现庄严感。 |
| 国风英雄、山海异兽、品牌东方感 | 新国潮东方奇幻 | 高流畅水墨动作 | 适合红金、矿物色与流线型动作。 |
| 决斗、追逐、武术、快速形变 | 高流畅水墨动作 | 漫画爆破 | 用单一笔触方向维持动作可读性。 |
| 赛博侦探、都市能力觉醒 | 赛璐璐霓虹图形科幻 | 手绘物理光效 | 用分色阴影、界面光而不是复杂写实机械。 |
| 温柔寓言、亲子、动物主角 | 绘本水粉/蜡笔 | 纸偶拼贴 | 降低写实面部漂移，强调材质与情绪。 |
| 诡异仪式、梦境、心理悬疑 | 彩窗光影与超现实拼贴 | 剪纸几何 | 让光块和不可能空间承担不安。 |
| 史诗自然、元素精灵、环保主题 | 自然元素粒子动画 | 手绘物理光效 | 单一元素（水、风、叶、萤光）最易实现。 |
| 定格喜剧、食物、手作产品 | 黏土定格微缩 | 波普爆破 | 物理材质和夸张表情稳定、辨识度高。 |

### 风格配方库

下列配方均为可描述的原创视觉特征；不要依赖特定作者、工作室或影视 IP 名称。用户指定参考名时，可保留为内部沟通，并优先使用下列可执行的中性描述。

#### 1. 天气光影日系动画（新海诚类天气美学）

**适合**：青春、重逢、孤独、雨后希望、城市奇遇。  
**整体画面风格**：`高精度日系 2D/3D 融合动画，清澈高饱和天空渐变，潮湿地面与玻璃反射，边缘柔和轮廓光，云层具有明确体积层次，人物表情克制而细腻，电影级动画品质。`  
**镜头/特效约束**：35mm 中景或 50mm 近景；只选一项天气变化：雨滴滑过玻璃、云影移动、逆光尘粒或水洼反光。禁止同时出现暴雨、极光、流星和闪电。

#### 2. 美式极简波普爆破风

**适合**：喜剧钩子、反击、产品卖点、动作停顿。  
**整体画面风格**：`扁平高对比波普动画，红黄蓝黑四色主调，粗黑轮廓，双色网点阴影，干净留白，手绘速度线与抽象爆破形状，角色肢体夸张清晰，不生成任何文字或拟声词。`  
**镜头/特效约束**：24-35mm 全身或中景；冲击只用“放射形色块 + 一次短促抖动”，不要要求复杂碎片、火焰和多次爆炸。

#### 3. 手绘物理光效风

**适合**：能量觉醒、魔法物件、治愈、技能启动。  
**整体画面风格**：`高品质角色动画叠加逐帧手绘特效，发光线条具有粗细变化，双色烟雾层、短弧闪电、星点粒子与环境受光一致，保留手工不规则边缘，明亮但不过曝。`  
**镜头/特效约束**：50mm 中近景；让光从单一来源开始，沿手臂、道具或地面扩散一次；环境只产生一次对应反光。

#### 4. 古朴魔法与羊皮纸炼金风

**适合**：秘密配方、遗迹、古老道具、低调奇幻。  
**整体画面风格**：`古朴魔法动画，羊皮纸米褐、氧化铜绿和烛火金为主色，木材与黄铜有磨损纹理，抽象同心几何光环缓慢旋转，蜡烛暖光与冷色阴影并存，所有符号均为不可读装饰。`  
**镜头/特效约束**：50mm 道具近景或 35mm 半身镜；只启动一个道具或一圈光环，避免满屏符文、悬浮书页和多层召唤阵。

#### 5. 剪纸贴图与诡异几何风

**适合**：童话惊悚、梦境、空间裂缝、悬疑转折。  
**整体画面风格**：`多层手工剪纸拼贴动画，纸纤维边缘清晰，前中后景有明显投影与视差，低饱和朱红、靛青和黑色，平面人物与不可能几何门洞并置，轻微逐帧抖动。`  
**镜头/特效约束**：35mm 正侧构图；一次几何门洞折叠或一张纸影横移即可，禁止要求复杂三维翻转、无数碎纸和高速镜头穿越。

#### 6. 神性与具象化大魔导风

**适合**：神祇登场、最终试炼、宏大召唤、品牌主视觉。  
**整体画面风格**：`庄严的高魔法动画，巨大但简洁的光束、悬浮阶梯和多层半透明几何圆环，人物被置于尺度明确的中心构图，金白主光配深蓝阴影，布料与发丝受风带动，神圣但不刺眼。`  
**镜头/特效约束**：24-35mm 全景起势；每镜只揭示一层尺度，例如光束落下或阶梯显现，不同时生成完整宫殿、群像和多种法阵。

#### 7. 新国潮东方奇幻风

**适合**：国风英雄、节庆、神兽、东方品牌、山海题材。  
**整体画面风格**：`新国潮东方奇幻动画，朱砂红、石青、孔雀绿和金箔点缀，矿物颜料颗粒，飞动丝绸与云气形成流线，木雕/漆器/瓷釉材质清楚，人物轮廓利落，传统元素抽象化且不包含文字。`  
**镜头/特效约束**：35mm 人物中景或 24mm 建立镜头；选择一种东方元素运动：云气绕行、金箔飞散、丝带掠过或神兽剪影经过。

#### 8. 高流畅水墨动作风

**适合**：武术、奔跑、器物挥击、变身、强节奏转场。  
**整体画面风格**：`高速流动的水墨动作动画，干湿笔触边缘、飞白和墨点随肢体方向拉出，墨色层次从浓黑到淡灰，单一朱红或金色作为重点击，人物动作轮廓清楚、重心真实。`  
**镜头/特效约束**：35mm 侧向全身或 50mm 半身；每次动作只有一条主笔势，镜头沿同一方向跟随，禁止让墨迹吞没人脸或遮住关键动作。

#### 9. 赛璐璐霓虹图形科幻风

**适合**：都市能力、赛博悬疑、潮流产品、夜景。  
**整体画面风格**：`赛璐璐分色动画，深靛蓝底色、品红和青绿霓虹边缘光，硬边两级阴影，简洁几何 HUD 光块但无可读字符，雨夜反射与稳定的透视线。`  
**镜头/特效约束**：35mm 中景；一次扫描光掠过、一次霓虹反光或一次边缘残影，避免复杂 UI、密集乱码和无限镜面。

#### 10. 绘本水粉与蜡笔质感风

**适合**：亲子、动物、治愈、轻喜剧、乡野故事。  
**整体画面风格**：`手绘水粉和蜡笔绘本动画，纸张颗粒可见，边缘略有不均匀涂色，低对比柔和配色，圆润角色比例，暖阳或窗边漫反射光，表情友好清楚。`  
**镜头/特效约束**：50mm 中近景；用一阵风、漂浮花瓣或小范围色彩晕染表达情绪，不使用爆炸、闪电或高密度粒子。

#### 11. 彩窗光影与超现实拼贴风

**适合**：宗教寓言、心理悬疑、梦境转场、仪式感。  
**整体画面风格**：`半透明彩色玻璃光块与拼贴纸纹并置，深蓝、琥珀、紫红的折射投影落在角色与地面，人物轮廓写实清楚，背景以简洁不可能空间制造不安。`  
**镜头/特效约束**：50mm 定镜或缓慢推近；只让一片彩光穿过人物或一面墙折叠一次，避免角色身体被切碎或过度变形。

#### 12. 黏土定格微缩风

**适合**：手作、食物、可爱怪物、轻喜剧、产品开箱。  
**整体画面风格**：`高品质黏土定格动画，手指压痕与软陶颗粒可见，微缩实景布光，低帧率的可控停顿感，柔和阴影，颜色饱满，角色表情夸张但清楚。`  
**镜头/特效约束**：50mm 中景；只做一次定格跳跃、物件弹起或软陶挤压变形，避免连续复杂打斗。

#### 13. 自然元素粒子童话风

**适合**：森林、疗愈、环保、元素伙伴、自然品牌。  
**整体画面风格**：`自然童话动画，叶片、萤光、雾气或水汽只选择一种作为主粒子，柔和体积光穿过植物层次，角色与环境共享同一色温，材质湿润而真实。`  
**镜头/特效约束**：35mm 中景；让主元素沿清晰路径移动一次，如萤光从瓶口上升或叶片随风围出半圈。

#### 14. 低多边形晶体神话风

**适合**：科技感、矿石、能量核心、抽象品牌视觉。  
**整体画面风格**：`精简低多边形动画，切面晶体有明确折射与色块，深色背景中保留一到两种主色，角色和道具轮廓平滑，几何体稳定且不熔化。`  
**镜头/特效约束**：35mm；只让一块核心晶体旋转、裂开或亮起，不要让全场景同时晶体化。

## 两个工作示例

### 示例 A：9:16 对话短剧

**命题**：女儿在父亲办公室发现一张陌生人的合照。

| 镜号 | 戏剧功能 | 起始状态 -> 主要动作 -> 结束状态 | 镜头、画风与声音 | 承接 |
|---|---|---|---|---|
| 1，2 秒 | 钩子 | 女儿站在办公桌前，手按照片 -> 把照片推向父亲 -> 父亲视线落在照片上、僵住 | `主体：女儿与父亲。场景：夜间办公室。` 50mm 女儿近景猛推；纸张划过桌面的声音后静默；无文字、无说话 | 镜 2 从父亲看向画面左侧的照片接入 |
| 2，4 秒 | 对峙 | 父亲坐着，照片在前景 -> 手指压住照片边缘 -> 目光避开女儿 | 50mm 父亲反打中近景；台灯电流声；整体画风锁定；无台词 | 镜 3 从女儿画面右侧望向父亲接入 |
| 3，4 秒 | 悬念 | 女儿握紧照片 -> 翻到背面 -> 发现背面被撕去一角后停住 | 85mm 手部特写，焦点转到照片缺角；无配乐，只剩呼吸与纸张摩擦声；不生成任何文字 | 切在她僵住的反应上 |

### 示例 B：16:9 横屏悬疑短片

**命题**：夜班保安发现空楼里有一扇本不该亮的门。

1. 建立镜头：`主体：夜班保安。场景：空旷走廊。` 35mm 大全景，尽头一扇门透出暖光，保安从画面左侧进入。
2. 跟拍镜头：35mm 中景，保安沿同一方向靠近，手电光掠过地面，脚步声成为节拍。
3. 物件特写：85mm，门把手上有新鲜水珠，保安的手停在把手前，没有立刻开门。
4. 过肩镜头：50mm，门缝内传来一阵断续电流杂音；镜头停在他收紧的手指上。
5. 收束：35mm 缓慢后拉，揭示走廊另一端还有一个相同的保安背影，保持不解释；无任何文字或人物说话。

## 禁止事项

- 不要把镜头表写成无动作的形容词堆砌，如“高级、震撼、电影感”。改为可见的构图、光线、材质和行为。
- 不要一镜完成跨空间、跨时间、跨情绪的大段剧情。
- 不要把所有镜头都写成慢推、特写或手持；景别和运动应有叙事理由。
- 不要用真实可识别人物或受保护 IP 作为默认创作锚点；采用原创角色与可描述的视觉特征。
