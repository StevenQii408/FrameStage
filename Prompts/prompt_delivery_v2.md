# 可复制 Prompt 紧凑交付规范 v2

本规范补充动作交付、完整事件交付与剧本导演规范，仅控制新建 Prompt 的确定性渲染。视觉分析、事件判断、模型、API Key 和 Agent 调用预算保持原策略。

## 输出与审计分离

- 可复制正文只放生成模型需要的主体、场景、初始状态、动作或时序、摄影、已知画风、终态、规格及必要约束。
- 来源镜号、切点、帧证据、原始响应、创作假设、声音尚未生成及时间不是源片实测等说明保留在 `contract.delivery`，不重复拼进正文。
- 不用字符上限截断动作、对白或风格；“再次饮用”等有效重复动作必须保留。对白原文不作标点去重或摘要。
- 未知的可选摄影和空间字段不渲染。必需信息不足时保留观察与警告，不补造内容，不因格式校验追加模型调用。
- 已确定全局画风逐字继承；部分视觉观察继续保留其镜头级范围，不能因删除待确认提示而一并删除有效特征。

## 首帧图片

包含主体、场景、0 秒状态、已知静态摄影、画风和图像规格。只使用首个实际呈现的来源镜头，不把后续入场人物、动作结果、声音、视频时长、动作时间线或收束段加入首帧。

无文字、字幕、Logo、水印等图片约束只表达一次。首帧静态属性不额外伪装成一种运镜。

## 视频

- 单一语义阶段直接写完整动作，不强制 `0–D 秒`。
- 多阶段只保留一条时间线；必要的切镜和摄影安排写在对应动作段，剧本对白按原归属与顺序呈现。连续摄影可以单列一次统一摄影段。
- 终态只描述最后状态，不再复述整个动作过程。
- 参考视频只分析画面，声音约束及必要生成拟音不冒充原片音轨事实；无对白要求只写一次。剧本模式保留原对白与声音，禁止错误套用参考视频的无对白约束。
- 画幅、分辨率继承已保存生成设置；不同显式规格不能被静默合并为一个剧本生成片段。帧抽样分辨率不等于目标视频分辨率。

示例（多阶段）：

```text
主体：男孩、女子；事件道具：玻璃杯。
场景：客厅。
视频规格：时长 6 秒；分辨率 1080p；横屏 16:9。
起点：男孩双手持杯，女子站在他面前。
动作时间线：
0–2.5 秒：男孩递出杯子，女子接稳；中景，固定摄影。
2.5–6 秒：女子举杯饮用，随后放下杯子；切至女子近景。
整体画面风格：已核验的完整画风段落。
结束状态：女子持杯于胸前，男孩抬头看她。
声音与约束：无对白、旁白；角色与道具保持连续；不生成文字、字幕、Logo或水印。
```

示例时间和摄影仅用于说明格式，不能套入没有这些证据或创作决策的任务。

## 时间与校验

精确时间保留原值；正文默认显示两位小数、去尾零。若短阶段因此坍缩则提高展示精度，不删除或拉长阶段。`delivery.display_timing` 保存精确值与展示值映射，规格总时长及阶段边界共用该映射。

`delivery.prompt_lint` 保存所用模板和本地结构校验结果：检查必需合同字段、未知可选占位、重复段落、首帧混入视频字段、画幅、展示时长及阶段时间一致性。结构通过不代表模型语义一定正确。

## 版本与历史

- 来源首帧：`first-frame-v7`；来源视频：`seedance-video-v8`。
- 剧本来源：`script-first-frame-v2` / `seedance-script-v2`；剧本片段：`script-sequence.v2`。
- 事件 Agent：`event-agent-render.v4`。
- 历史模板继续注册；读取历史结果不改正文。历史剧本应用画风仍使用保存的旧模板，历史事件应用画风只替换画风段，不重排事件或时间线。新建任务使用新渲染器。

实现入口：`backend/app/services/prompt_delivery.py`、`prompt_service.py`、`backend/app/script_director/render.py`、`sequences.py`、`backend/app/event_agent/rendering.py`。
