# 文字剧本导演规范 v3

新建 Prompt 同时遵循 [可复制 Prompt 交付 v2](prompt_delivery_v2.md)：动作、摄影与对白共用时序，首帧只保留第一来源可见人物，规格继承来源设置；创作来源说明保留在合同中。历史 v1 渲染继续兼容。

本规范仅用于文字剧本创作，不改变参考视频的事实观察与静音生成规则。

## 原文与创作的界限

- 人物介绍、场景标题和作者备注作为设定保存，不独立生成镜头。
- 原文对白按说话人保存；对白、旁白、画外拟音不作为独立肢体动作。
- 模型只选择预编译的对白ID；本地按ID提取原文字符区间，不要求模型计算中文字数或重复生成台词。长对白的分段ID也由本地按标点无损建立。
- 允许补全必要站位、机位、构图和光线；补全内容须独立标记，不伪称原文事实。
- 不改变剧情结果，不从枪声推断人物死亡，不把心理活动直接写成不可见动作。

## 镜头与事件

- 按目标、冲突、信息揭示和情绪转折组织事件，不按标点、段落或固定两句话切镜。
- 连贯事件可以包含双人镜头、反应与必要特写；不同人物发言不自动切镜。
- 每镜记录镜头功能及简短切换理由，不输出内部思维链。
- 景别、焦段、机位角度、运镜分别记录；仰拍不等同于俯仰运镜。
- 默认保持轴线、视线、人物位置和道具状态；有意跨轴需重新建立空间。
- 首帧必须为当前镜头动作起点，不提前呈现交接、逃离等完成结果。

## 声音与时长

- 剧本模式默认保留对白；旧规范的“无台词、无人声”不适用于本模式。
- 图片始终禁止字幕与可读文字；保存对白不代表已生成语音、配音或口型。
- 秒数是建议表演时长，不是原视频测量值。优先考虑对白、停顿与动作耗时。
- 当前单段生成上限12秒，长对白可在标点处无损分段，不能截断或改写原台词。
- 单一动作可自然概括；多个语义阶段使用明确时间顺序，不四等分微动作。

## 输出顺序

主体及共享人物设定 → 场景与首帧状态 → 按时序组织的动作和对白 → 摄影计划 → 整体画面风格 → 结束状态 → 时长、分辨率与画幅。

## Agent 预算

每窗口最多2次Flash请求（第二次用于工具补查或局部纠错，二者共用预算），最多4个按需本地只读工具请求。失败保留原文及审计，采用明确标记的保守规划；不得调用本地模型、升级云端模型或无限重试。
