## 如何补充你的文档

后续可以把独立画风文档放在本目录，例如 `visual_style_guidelines.md`，也可以直接在聊天中提供文件。建议每种风格包含：

1. 媒介：写实摄影、3D 动画、2D 手绘、定格、混合等。
2. 可见的角色与表情特征：头身比例、轮廓、面部结构、表情幅度。
3. 光影、渲染、材质与色彩：使用能在帧中核验的具体特征，不只写“电影感”。
4. 特效：区分全片美术特征与单镜可见特效，避免自动添加不存在的粒子或光效。
5. 正例、反例和适用条件：最好附图片或镜头编号。
6. 生成建议：允许的风格锚点、品质要求与禁用项，和原片观察明确分开。

新增文档**不会自动进入生产 Prompt**。接入时先审核与现有规范的冲突，再新增规则版本、来源 SHA-256、对应测试和新模板版本；不能仅修改旧规则而让历史任务悄然变化。不要修改 `ai-shortfilm-prompts` 独立仓库。

## 当前实现入口

- `backend/app/prompt_profiles/style-rules.v1.json`：已审核的观察指导、生成焦段建议和中文交付顺序。
- `backend/app/services/perception.py`：双阶段分析；静态画风与动态证据分别处理。
- `backend/app/services/prompt_service.py`：确定性中文模板，不让 Flash 自由编排下游格式。

画风观察记录媒介、角色造型、渲染与光影、材质、色彩及可见特效，并保留帧证据。全片概览只作对照，不覆盖当前镜头的不同画风。

## 事实与创作的边界

- 视觉焦段类别是估计，不等于测量出的毫米焦段。具体 24/35/50/85mm 明确标注为生成建议。
- 当前不分析音轨。声音段是生成建议，不声称听到了原片声音；具体拟音只能参考已识别动作，不增加剧情。
- 生成 0 秒状态来自本镜最早可用帧；这不意味着抽样帧恰好落在源片起点。缺少起始证据时标为待人工设定，不能拿中间清晰帧或动作结果代替。
- 未识别的媒介保持待确认，不能默认为写实摄影；动画的光滑材质不默认进入“塑料皮肤”负面约束。
- 首帧只写起点；视频按已观察动作排序，时间段是生成编排建议，不是原片动作时间实测。

## 完整中文交付

镜头合同 → 首帧意图说明 → 首帧图片提示词 → Seedance 中文图生视频提示词 → 素材与设置建议 → 连续性检查。

Inspector 可以查看并复制以上内容；结构和来源版本保存在 `PromptBundle.contract.delivery`，随现有 JSON 导出。连续性检查中的人工待确认项不能被当作自动验收通过。
