# 画风观察与高密度表达审核规范

当前生产 Prompt 位于 `backend/app/style_direct/prompts.py`，版本 `style-direct.prompts.v3.12`。本文件用于讨论与修改建议，不自动注入模型。系统仍先分析并给出可用画风，用户可以选择经证据核验的生成配方，不需要从整库查词。

## 最新修订：独立控制点与最多三项生成配方

参考核验 v3 按独立视觉控制点计数：比例、块面发束、阴影边缘、明暗组织、高光范围可以来自少量可靠事实，不要求为凑三个 ID 拆开句子。同义表达不重复计数，通用媒介不算区别性控制点。`visual_fit` 仍需至少两个维度、三个控制点、至少一个相关近邻及所有已有完整支持的竞争者比较；未穷尽的近邻在来源记录和不确定信息中保存。`distinctive` 继续要求完整区别性比较，不能将视觉适配当作工作室来源鉴定。

阶段 B 同一次请求可给出零到三项推荐，每项独立校验证据和范围；全部不合格则保留具体观察，不按排名自动套词。模型只返回短引用及理由，完整生成配方由后端可信词库补出，不向模型要求重复大段模板。本轮不增加强制云端请求或取证预算。

选用完整配方是显式创作覆盖，名称与完整库原文进入生成 Prompt，原观察与模型 reference 不变。用户可随后手工修改；版本、库哈希与历史归档保护仍适用。渲染器为 `style-compact.v7`，避免家族名和正文重复比例概念，保留眼部面积及块面发束等互补控制点。特殊情境中的皮肤泛红不会因误标 shared 就晋升为全局画风。使用与原镜头／生成片段关系见 `../STYLE_CHOICES_AND_SEQUENCES.md`。

多模态请求显式使用 JSON Object，Schema 在本地校验。阶段A空数组只触发一次简化看图纠错，使用同一组真实图片，不增加请求上限。两次仍为空则停止画风推断，基础观察标为“非完整画风”，不换用无关名称。分镜计划独立固定，不受画风失败影响。详见 `STYLE_PLAN_STABILITY.md`。

## 当前生产决策：候选召回 → 原图区别核验

新分析以 `reference` 保存一个有证据的生成视觉参考，不以旧 `anchor` 的全部微观组合作为必选门槛。旧锚点数据与验证仍保留兼容，以下旧组合说明不再是新版 reference 的决策规则。

候选由现有词库召回；定义、观察问题、反例和近邻用于引导第二次看图，不将完整生成配方灌入观察。参考分两种：`distinctive` 保持旧版区别性核验；`visual_fit` 推荐适合复现的非排他视觉方向，至少三条具体控制点覆盖两个维度，允许同媒介家族近邻重叠，但必须引用两个维度的共同证据并承认不可排他。证据不足不同于已证明重叠，仍拒绝名称。通用媒介、大眼和暖色不能单独命名；没有提到不能当成没有。候选全部不适合时reference=null，不改选无关画风。具体观察仍保留。

识别卡与生成短句分离；工作室/艺术家名只代表可比较的视觉参考，不鉴定来源，也不声称该机构所有作品有固定指纹。新增代表性参考卡维护在 `backend/app/style_direct/references.py`，其他类别继续使用自编词库定义作参考引导。

本地保留通过媒介与显式控制点检查的模型家族名，不能因同义表达未命中固定词串而改为“三维数字影像”；已验证 reference 优先渲染为“名称（视觉参考）＋可见控制点”。纯标点标准化不清空模型的合法精简句。

纠错后仍可在剩余预算内取证；若只剩一次请求，使用 `StyleVerificationV1` 同时新增观察及核验解释，不能覆盖原事实ID。仍最多四次真实请求、一次纠错、一轮取证、两块裁剪、180秒；联合核验最多4200输出token。预算耗尽、无新证据或失败时保留第一次有效结果，不强行补名称。

实现与验收边界见根目录 `STYLE_REFERENCE_REVIEW.md`。真实准确率需要独立人工样本及授权云端回归验证。

## A：观察，不命名来源

逐项检查媒介与体积、几何轮廓与抽象程度、综合色彩组织、阴影和高光、表面视觉表现。每条事实表达一个判断，保存观察对象 target、实际支持图片编号、置信度、唯一事实 ID 和 evidence_scope（shared/local/uncertain/历史unspecified）。不要将全体图片编号复制给所有事实。不要仅返回“3D、暖色、柔光”；不可见项给出原因。否定观察作为排除信息，不挤占最终风格句。

不保存人物发型身份、发色、服装、道具、地点为画风，但可保留有证据的块面化发束等表现方式。删除内容句时，不留下失去对象的“哑光质感”等残句。局部湿润等效果单独存储；暗示情绪的解释移至 uncertainties，不作事实。不推测引擎、光照算法、艺术家或工作室。静态图片不能证明动作节奏、逐帧抖动或帧率。压缩噪声不直接认定为笔触或颗粒。

所有自然语言字段要求中文；历史或异常英文输出仍需本地兼容，不因语言不同清空有效观察。中英文内容及技术过滤一致，独立有效短句可保留。合法的“暖色调”“柔光”不以字数短为由拒绝，空话不能因为长就算有效。

## 有疑点：自己定位一次，不把选择题交给用户

疑点必须具体、可用原图验证，并说明归一化区域和预期证据。阶段A可提出gaps，阶段B在候选歧义时也可提出investigation_gaps，两者共享一轮、最多两块裁剪。核验后最多再裁决一次。常规两次、总计最多四次实际请求、一次JSON纠错、180秒总预算；阶段B输出上限3200 token避免新增证据结构被截断，实际输出计费并记录。重复整图/重复区域不追加调用，没有新证据就保留未知，不循环。矛盾不能静默覆盖原事实，只记入不确定信息。

## B：观察事实 → 专业概念 → 可执行描述

仍提供图片，避免 sparse tags 信息瓶颈。每条专业句必须引用同维度事实 ID，不得在合法引用后夹带新特征。

例如已有“圆弧轮廓、五官细节简化”，可以写“曲线主导的圆润造型，五官适度简化”；不能自动补上未观察到的夸张头身比例、工作室来源、暖色或柔光。

代表性名称单独输出为可选 reference，不写进观察事实。候选来自 `Prompts/cinema_style_library` 编译到后端包内的 `cinema_library.v1.json`，其中完整签名只辅助召回；生产选择根据精简识别卡与原图进行区别核验。旧 `anchors.v1.json` 仅保留历史ID参考。Flash可以全部拒绝，不能因三维、大眼就硬套迪士尼或皮克斯；接受时 matched_features 保存逐字 quote 和同维度事实ID，另有区别性依据及近邻裁决。“某某式”是生成视觉参考，不是原作来源鉴定。

本地 `lexicon.py` 只用于中英文检索别名规范化，不扩写事实。否定词保持原位置，同义词不重复计分；通用媒介词只筛选大类。运行时最多12个相关候选，小家族完整进入比较，大集合全零时按类别探索；顺序不是相似度排序。标签稀疏或组合不完整可进行语义裁决，但不自动接受名称。reference 的 alternative_assessments 比较最近候选及已经完整支持的竞争者；不能因观察没提到某特征就断言它不存在。错误引用、局部证据、泛词和信息不足仍拒绝具体名称。仅在比较解释中允许“区别于写实毛发模拟”等负向表现方式描述，发色、衣物与算法猜测仍过滤。只有定位到可取证的视觉缺口才补充，不因来源不可鉴定而反复重试。

每个有效维度同时输出 8–20 字的完整精简短语 `concise_phrase`。没有精确流派名不影响输出具体特征；无法确认名称则以真实媒介开头。高密度是每句话都有轮廓、比例、色彩、阴影、表面等控制点，不是“高级、电影感、震撼”堆砌。

精简短语不是新创作：保持引用观察和详细句的冷暖、饱和度、阴影边界等控制点，不能将冷灰低饱和变成暖金高饱和，不能将局部暖高光变成全片暖调。已知明确矛盾由本地恢复观察或重建短句，不额外收费重写。这是有限规则，不是完整语义一致性证明。匹配器 `style-signatures.v3` 支持文字组合和模型语义引用两条路径；校验通过不证明真实识别准确率。

## 确定性渲染

以已验证的视觉参考、旧锚点或有依据的风格家族开头，按造型 → 色彩 → 光影 → 表面表现保留具体控制点，自动观察句目标60–100字、硬上限120字；明确选择的完整创作配方不截成这个自动摘要预算。渲染器style-compact.v7先汇总同维度的全部有效描述，每条取一个互补控制点，再在字数预算内追加，不因第一条比例描述丢弃第二条发束描述。各维度先保留一项，再追加造型与光影细节。否定与通用媒介说明不抢占空间。详细解释另存；证据少允许更短，不填无证据细节。景深、焦点与构图属于单镜摄影。单帧效果scope=local/image_alias，保存在local_prompts，不继承到全局。

视频抽帧后先建立冻结基础画风，再逐镜继承，每镜分析后立即交付完整首帧和 Seedance。明确局部媒介或造型冲突由本镜证据隔离，不增加额外云端调用；没有明显冲突仍继承基础画风。任务结束不静默修改已经交付的文本。首帧和 Seedance 使用同一版本。本版模型generation_constraints固定为空；历史字段仍可读取审计，但新渲染不再追加“生成画风约束（非原片事实）”，有价值的视觉表现合入整体画风。动作、摄影与连续性约束不受影响。

后续补充画风文档时，优先提供具体正反例及可见线索，而非仅提供 IP 名称。调整先更新生产 Prompt 版本、黄金样例与快照，旧任务不静默重算。
