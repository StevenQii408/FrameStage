# 动作链、语义阶段与按需时序交付 v1（2026-11-11 修订）

本文件是项目运行时动作交付的审核补充规则，优先于旧 Seedance 文档中固定分时段示例。旧示例作为手工创作参考保留，不自动照搬。主体→场景→动作→镜头→整体画风→声音→收束顺序、首帧只写起始状态的规则不变。

## 三个不同单位

- 来源镜头保留真实剪辑边界，不设置4.8秒强拆。生成片段是一条能在生成预算内完整表达的动作链，其服务能力上限不反向修改来源切点。
- 详细动作步骤：1–4个有意义的可见动作，不强制四步，不因动词数量自动拆镜。
- 语义阶段：不同的先后行为目的或明显状态变化。一阶段可以包含多个步骤；单动作不需要阶段时间表。

当前视频先确定镜头范围，再分析镜内动作，导出的 ActionAtom 是兼容记录，并不是精确动作时间标注。短镜过多应检查切点保护和合并规则，不能通过隐藏动作或编造时间解决。本版本不改拆镜边界。

## 模型输出

- subject_action：简洁主动作链，通常25–80字；软目标，不补字、不截断重要事件。
- action_steps：保留详细观察，用于审计和保护独立事件，不直接均分成若干时段。
- accompanying_states：最多两项有证据的伴随状态。步骤排在后面不代表随后发生；采样帧不证明全程注视，头部朝向不证明视线。
- action_phases：可选2–3阶段。description写实际动作；source_step_indices引用1起的来源步骤，按序恰好覆盖；frames/note/confidence引用有效本镜证据。
- generation_start_seconds/generation_end_seconds：仅在多阶段确需时间约束且可合理安排时提供。属于生成建议，不能说是原片动作实测。连续覆盖明确的建议生成时长，禁止按步骤数均分。依据不足省略秒数，保留先后顺序。

保持姿态、注视等不是自动新增的后续阶段。拿起→饮用→放下可以概括为一条动作链；搅拌后舀起、递出后接住、饮用后打碎等独立事件不得被概括掉。心理因果必须与可见事实分离：画面仅支持皱眉时，不把“发现饮料有毒”写成事实。

## 输出示例

单动作：

```text
动作：女子饮用杯中液体。
伴随状态（采样帧可见，不推定全程）：男孩抬头注视女子。
```

有时间安排的两阶段（以下秒数仅为创作示例，不是固定比例）：

```text
动作时间安排（生成编排建议，不是原片动作时间实测）：
0–2.5 秒：女子拿起杯子并饮用。
2.5–5 秒：女子放下杯子并皱眉。
```

时间依据不足：

```text
动作阶段（仅表示观察到的先后顺序）：
阶段 1：女子拿起杯子并饮用。
阶段 2：女子放下杯子并皱眉。
```

## 校验、降级与历史

- 无效阶段引用、来源步骤重复/缺失只影响阶段；有效主体动作和摄影结果继续保存。
- 时间安排有缺口、重叠或超预算时删除数值安排，保留阶段順序；不重新均分。
- 普通摘要可直接输出；本地关键事件检查仅保护明显遗漏，不宣称证明完整语义等价。触发时保留原步骤，并给出复核警告。
- 详细步骤、逐项证据（原响应提供时）、原始模型响应与生成表达同时保留；没有逐项证据时标为字段级，不造证据和精确时间。
- 生成总时长向上取整到半秒，仅对总预算进位一次，再分配必要阶段；证据帧时间保持原值。单动作不强加阶段时间表。
- 两次基础感知请求后，结构错误与视觉补证据共享最多一次额外请求；结构纠正引用原图、原编号及具体错误，成功字段锁定保留，不能伪造证据。
- 静态成功而动态失败时保留静态场景，动态单独待复核，视频方案标为草案。未知摄影细节和局部画风提示不直接否定主要动作。旧任务不静默重算。
- 前端默认显示主动作与必要阶段，详细观察折叠显示；帧时间戳明确为证据时间，不是动作完成时间。

本修订不扩充画风库、不更改云端模型或Key、不引入生成API。真实语义质量仍需用授权素材和人工标注验收。
